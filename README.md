# 数字图片复核台

这个仓库用于灵境 AI 第一阶段考核。项目正在从单张数字分类演示，改成可以批量导入、检查、纠错和导出的本地复核工具。

## 这次要解决的问题

识别接口输出一个数字，并不意味着这张图片就处理完了。还要知道哪些结果值得先检查、同一张图片是否重复导入、修改过什么、导出的数字来自模型还是人工确认。

本次实现范围：
- PyTorch 手写残差网络和真实图像分类实验。
- SQLite 保存批次、图片、预测和复核事件。
- 按不确定度排序的复核队列，并与随机检查做同预算比较。
- 纠错保留原预测；版本冲突不覆盖别人的修改；重复请求不重复写入。
- CSV 导出清楚区分未确认预测与已确认标签。
