# 从数字演示到自然图片识别

## 旧版为什么在手机照片上失效

2026-11-12 检查了本机实际上传记录及其预处理输入。照片包含横格纸、明显阴影、倾斜和大量空白，一张还含多个数字。旧模型只看 8×8 灰度图，整幅照片缩小后笔画几乎消失，背景明暗成为主要输入。可选的固定阈值居中会把阴影和纸上线条一起当成笔画，无法解决定位问题。

此外，UCI Digits 的小图分布与手机照片相差很大；十分类模型总会在 0—9 中选择一个答案，没有可靠的类别外拒绝能力。之前的公开测试集检查覆盖了数值复现，却没有验证真实拍摄场景，不能证明交付工具满足这种使用需求。私有上传图片保留在本机 `var/` 中，不上传到公开仓库。

## 第一阶段：分类器对照（已保留，非主结果）

增加 `objects/` 应用，采用 PyTorch 官方 torchvision ResNet50、IMAGENET1K_V2 预训练权重。它是在自然照片上训练的 1000 类分类模型。保留 RGB、EXIF 方向和 224×224 输入，按照权重配套的标准预处理执行。权重下载来源、完整摘要和类别表保存在 `artifacts/objects/model-source.json`。

页面允许框选主体，分别展示标准中心取景与完整画面缩放的预测结果及前五候选。两种取景不一致或者首选得分低于 0.35 时提示核对。这个提示阈值是交互规则，没有经过真实用户数据校准，不能保证拒绝所有错误或类别外输入。

继承复核思想，预测记录保持不变，确认名称另存；支持无法判断、撤回、版本冲突检查、重试回执、原图回看和 CSV 导出。英文类别名始终保留，部分常见类别附中文显示。

## 分类器的能力范围

常见动物、食品、车辆、日用品以及部分场景，具体以页面中可搜索的 1000 类为准。它不是 OCR、自动物体检测或开放词汇模型；多主体照片请框选。人、手写文字、罕见物品及类别外内容仍可能被错误分类，softmax 高分也不能排除这种情况。

这是对预训练模型的应用和后端改造，没有声称这些权重由本项目从零训练。原手写残差网络及训练记录保留，用于原考核中手写网络的证据。官方模型能力、真实照片验证结果与项目自己训练的成绩分开记录。

参考：https://docs.pytorch.org/vision/0.17/models/generated/torchvision.models.resnet50.html

## GitHub 调研后的主流程

阅读上游代码后，新增 YOLO11s 自动物体检测作为主结果，ResNet50 收入折叠的辅助对照。采用官方等比例缩放补边、NMS 和框坐标恢复；局部识别的框再映射回原图。支持 COCO 的 80 类物体，允许没有检测结果。不再将分类器在类别表内强选的名称显示成可靠的主判断。实际方案和未采用方向见 `research/OBJECT_PROJECTS.md`。

这提升了多物体照片的可用性，但仍有漏检和误报，没有证据宣称达到某个真实用户照片准确率。五张公开照片的全部实际输出保存在 `artifacts/objects/detection-smoke.json`。
