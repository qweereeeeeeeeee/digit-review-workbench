# 复核实验：先写规则，再看结果

2026-10-26，本次改造继续使用已训练的手写 ResNet。该模型的 270 张保留测试集及失败情况在第一版已被看过，因此以下是回顾性队列分析，不能称为全新盲测，也不能用来重新调模型后继续宣传无偏准确率。

问题：固定检查预算时，按模型置信度从低到高检查，能比随机顺序更早遇到错误吗？

- 顺序 A：最大类别概率升序；相同概率按 sample_id 排序。
- 顺序 B：固定种子 2026，1000 次随机顺序，报告均值和 5%/95% 分位数。
- 预算：5、10、20、40、80 张，完整曲线另存 CSV。
- 原始 270 张与固定 σ=0.25 高斯噪声、亮度×0.5 两个派生场景分别报告。派生图是人工扰动，不伪称现场采集。
- 不根据测试标签排序；标签只用于事后判断命中多少错误。
- 不模拟人一定纠正成功：这里只测“遇到错误的数量”，不是人工纠错准确率，也不是节省工时。
- 允许出现优先队列不如随机的情况，全部结果保留。

后端验收：重复导入、同一请求重试、并发版本冲突、未知任务、空白图片、非法标签、导出字段区分、纠错不覆盖原预测、事件持久化。界面验收要真实操作一次上传、确认、更改、撤回复核和 CSV 导出。
