# 代码理解与答辩路线

请提交者实际操作后，使用自己的语言回答。以下是技术提示，不是假造的个人感悟。

1. `src/model.py`：为什么相加之前需要 1×1 卷积？当通道数或步幅变化时，shortcut 将输入映射到与残差分支相同的形状；否则使用恒等映射。
2. 张量形状：N×1×8×8 → N×16×8×8 → N×32×4×4 → N×64×2×2 → N×64 → N×10。
3. 为什么最后不在模型里加 softmax？CrossEntropyLoss 接收 logits；推理和概率评价才使用 softmax。
4. 为什么不是标准 ResNet-18？本项目用六个 BasicBlock 和小图 stem，避免 7×7 stride-2 和池化过早丢失笔画。名称是 small-image ResNet。
5. `train()` 与 `eval()`：BatchNorm 在训练时更新统计量，评估时固定统计量。验证与推理同时关闭梯度。
6. 四份划分有什么用？训练梯度、验证选轮次、校准估温度与阈值、测试最后评分。测试集不负责调参。
7. 温度缩放会提高准确率吗？正温度不改变 argmax，通常用于调整概率可信程度；不保证测试 ECE 改善。
8. 覆盖率为何必须报告？拒绝困难样本可提高接受样本准确率，但牺牲自动处理比例；两者必须一起看。
9. 未知图像为什么仍可能高置信？softmax 总在已知十类间分配概率，拒识阈值不是可靠的分布外检测器。
10. 遮挡图是什么？每次将一个像素置零，比较原预测类别概率变化；64 个变体批量推理。它依赖扰动方式，不等同因果解释。
11. 数据泄漏如何排查？检查划分索引、跨划分重复图片和所有拟合步骤的数据来源。
12. 怎样修改和定位错误？先运行测试；修改 block 通道数会被形状/反传测试捕获；错误输入会返回 422；权重不匹配会在启动时失败。

1. 打开两个页面并选中同一记录。先在一个页面保存，再在另一个页面保存；解释为什么第二次得到 409，以及版本号在哪里比较。
