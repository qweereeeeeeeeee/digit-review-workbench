# 本地接口与数据约定

启动服务后 `/docs` 提供完整字段、类型和交互请求。下面记录容易误用的约定。

| 方法与路径 | 用途 |
|---|---|
| GET `/api/health` | 模型加载状态及 SHA-256 |
| POST `/api/batches/import` | Base64 图片、笔画颜色、可选居中，建立批次 |
| POST `/api/batches/demo` | 从保留测试集建立演示批次 |
| GET `/api/batches` | 批次数量与处理状态汇总 |
| GET `/api/batches/{id}/items` | 按状态、顺序分页，最多 100 条 |
| GET `/api/items/{id}` | 原图（如有）、预测、最终标签和修改记录 |
| POST `/api/items/{id}/review` | 确认、纠正、无法辨认或撤回 |
| GET `/api/batches/{id}/export` | UTF-8 BOM CSV，保留原始预测 |
| GET `/api/model` | 固定模型的实验报告 |
| GET `/api/experiment` | 回顾性队列分析结果 |

写请求需要 UUID 格式 `request_id`。复核还需要当前 `version`；读取记录后再填写，不能猜测。确认时 `action=review`，`label` 为整数 0–9；`unreadable` 和 `reopen` 不接受标签。

同一个请求编号和相同内容返回第一次保存的结果，即使记录随后已经被修改也不会再执行。这是重试回执，不代表当前记录状态；需要最新状态时重新 GET。编号复用但内容不同、版本过期返回 409。资源不存在返回 404，输入不合法返回 422，请求超过 12 MB 返回 413，浏览器跨来源写入返回 403。

单张图片最多 2 MB、400 万像素，只接受 PNG/JPEG/WebP。批量导入全部检查通过后才写入事务。文件名仅作为显示和导出字段，不用于构造服务器文件路径。CSV 对可能被电子表格当成公式的文件名加前缀处理。

原图表与记录表使用外键；批次、记录、请求回执、事件的变更在事务中提交。SQLite 使用 WAL、10 秒连接等待，写事务显式获取锁。没有实现队列工作进程、认证、配额或跨服务器分布式锁，应保持本机使用。

`digest` 对上传图是原文件 SHA-256，对公开样本是小端 float32 像素摘要；结合批次来源理解，不能跨两种来源直接比较。`model_sha` 是权重文件摘要。`final_label` 为空可以是待复核或无法辨认，须同时读取 `status`。
